# Cardputer ADV Pet (в стиле Claude)

Пиксельный зверёк ходит по экрану и реагирует на звуки и клавиши.

На экране только питомец (без текста и баров). Клавиши: F — покормить, P — поиграть, S — спать/разбудить, любая другая — разбудить.
D — скрытый режим отладки: показывает уровни микрофона (для настройки порогов), повторное нажатие выключает.
Звуки: хлопок — радуется (искры), очень громко — пугается и убегает, долгая музыка/шум — танцует.
Еда/радость/энергия падают со временем и сохраняются в памяти; голодный или грустный питомец делает «грустные» глаза, спящий пускает пиксельные «z».

## Проверка без Cardputer
    sh sim/run.sh
Собирает `src/main.cpp` БЕЗ изменений для ПК (g++, с проверкой памяти), прогоняет сценарий со звуками и нажатиями
и рисует `sim/states.png` (все состояния) и `sim/pet.gif` (анимация). Нужны g++ и Python с Pillow.
Сценарий (хлопок, удар, музыка, клавиши) правится в `sim/sim_main.cpp`.
Это проверяет логику и вид, но не драйверы: микрофон, клавиатура и экран настоящего устройства в симуляторе — заглушки.

## Сборка .bin
    pip install platformio
    pio run
Файл: `.pio/build/cardputer/firmware.bin` (только приложение). Его кладут на SD-карту и запускают через Launcher.
Или залей папку в GitHub: Actions → Build firmware → артефакт `cardputer-pet-bin` (скачивается как .zip — распакуй, внутри firmware.bin).
